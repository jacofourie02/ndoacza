CSV Data & Directory Management

Member Import Guide — instructions for the person preparing the file

You do not need to use this Dashboard to prepare a CSV file. Ask the church administrator who will import the file to send you the correct blank template, confirm the congregation name to use, and provide the name of the responsible officer where required. Complete the template and return the CSV file to that administrator.

1. Choose and prepare the template

  • Use the Officer template for Overseers, Prophets, Evangelists, Elders, Priests, and Underdeacons, including their Sister role groups.
  • Use the Member template for Brothers, Sisters, Youth, and Children.
  • The first row contains column headings such as first_name. Keep that row, and do not rename, remove, or rearrange its columns. Enter one person per row; leave unused optional cells blank.
  • The Officer template has an officer_assignment_role column. Fill it only when the administrator gives you an assignment to enter; the accepted values depend on the officer's role. For an Elder or Priest they include Sunday School, Youth, Sunday School and Youth, Shepherd, Shepherd and Sunday School, Shepherd and Youth, Senior Citizens, Hospital, Resting, Freedom of the City, General, Special Tasks, Evangelical, Prophetic, and Evangelical / Prophetic. For an Overseer, Prophet, or Evangelist, use only Resting or Freedom of the City. Otherwise, leave it blank.
  • Complete the template in Excel or another spreadsheet program. Keep the column headings in the first worksheet. You can upload the completed file as .xlsx or save it as .csv. Format ID columns as Text before entering numbers so Excel does not remove leading zeros or round digits.

2. Complete the required columns

Every person row needs all five of these values:

  • role_group: the person's role. Use one of these exact values: Overseer, Overseer Sister, Prophet, Prophet Sister, Evangelist, Evangelist Sister, Elder, Elder Sister, Priest, Priest Sister, Underdeacon, Underdeacon Sister, Brother, Sister, Youth, or Child.
  • first_name and surname: the person's given name and family name.
  • id_number: the person's identity or passport number (6–13 characters). In Excel, format ID columns as Text before entering or pasting values; in Google Sheets, use Plain text. If a number has already been rounded or lost digits, changing its format will not restore them—re-enter it from a verified source. A South African ID number's first six digits are used to calculate the birth date.
  • congregation: the congregation's existing name, spelled as supplied by the administrator. Do not enter a new name or guess the spelling.

email and contact_number are optional contact details for the member. Enter the member's email address in email and phone number in contact_number. Initials and address are also optional. The examples below use made-up values; replace every example value with verified information before returning a file.

3. Name the responsible officer

In responsible_officer_surname, enter the active officer who is responsible for that person. The officer must already be in the directory. A surname is usually enough; if more than one eligible officer has that surname, enter the officer's first name and surname instead.

  • Elder or Elder Sister: the responsible Overseer.
  • Priest or Priest Sister: the responsible Elder.
  • Underdeacon, Underdeacon Sister, Brother, Sister, or Youth: the responsible Priest in the same congregation. For a Youth row, the responsible officer must be a Priest or an Elder with a Youth, Sunday School and Youth, or Shepherd and Youth assignment who serves that congregation.
  • Overseer, Prophet, or Evangelist: leave this column blank.
  • Child: leave this column blank when adding the child to a family head, as described below.

Prepare and import role groups in this order so each responsible officer is already available: Overseer, Prophet, and Evangelist; then Elder; then Priest; then Underdeacon; then Brother, Sister, and Youth; then Child. The administrator may ask you to provide a separate CSV file for each group.

4. Enter family and child information (optional)

Use family_type to describe the person's family. Leave it blank or enter Single Member for a person without family details. For a family head with children, choose the correct family type:

  • Family: enter the spouse's name in sister_name and the spouse's 6–13 digit ID number in sister_id_number. The spouse ID number is required for this family type. The spouse's phone number is optional; enter it in sister_contact_number.
  • Single Sister Family or Single Brother Family: use the correct category for the family head; do not enter spouse details.
  • 50/50 Sister Family or 50/50 Brother Family: use when the other spouse is not a church member. Do not enter spouse details; only the named adult and recorded children count as souls.

A family head can include up to five children in the same row using the matching child_1_... through child_5_... columns. For each new child, enter first name, surname, and ID/passport number (6–13 characters); initials are optional. Leave every column for an unused child blank. Do not partly fill a child's set of columns. Choose a family type other than Single Member when adding children this way.

5. Check the file and return it to the administrator

  • Check spelling, role names, congregation names, and officer names. Do not reuse an ID/passport number for two people.
  • Check that no required value is blank and that each child has both a first name and surname. A row with a missing required value or a partly completed child entry is rejected; none of that row is saved.
  • ID and passport numbers are sensitive information. Return the completed file only through the secure method approved by the church administrator.

The administrator uploads the file and receives a report showing which rows were imported and which need correction. If a row has an error, the administrator can share the row number and error so you can correct the spreadsheet and return it. Imports are restricted to the administrator's selected overseership.

Excel export groups the directory by congregation and preserves leading zeros. Use the Member Update File to edit existing records; use CSV or Excel import for new records.

The update file contains active records in the selected overseership. Keep the member_id, member_id_check, and child member ID columns unchanged. Blank cells keep the current value; enter [CLEAR] to erase an optional value. Dates inferred from an ID number are recalculated. This updates existing records only—it does not add members, remove children, or update archived/deceased records.
